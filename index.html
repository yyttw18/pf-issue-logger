系統資訊
PF Issue Logger Mobile v4.7
儲存方式：Browser Local Storage
掃碼格式：Code 128 / Code 39 / Code 93 / EAN / ITF / UPC 等常見一維條碼
資料模型：一筆 Issue Group 對應多個 PF Code
PF 取得方式：Barcode Scan + 標籤文字 OCR + 手動輸入
CSV：一列一 Issue／一列一 PF 兩種視圖
Excel：3 個工作表＋嵌入照片縮圖
Project：設定頁管理＋Issue Entry 快速新增
Owner：HW／ME／EC／BIOS／SW-Driver／MFG 複選
Product：Project＋SKU＋整機料號＋Description Master 與 Excel 匯入
Scanner：Color／Grayscale／Video Reverse／Threshold／Rotation 多階段解碼

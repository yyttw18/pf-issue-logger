# PF Issue Logger Mobile

Mobile-first PF issue logger for iPhone Safari and Android Chrome.

## GitHub Pages deployment

1. Create a **Public** GitHub repository named `pf-issue-logger`.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, then click **Save**.
6. The site URL will be `https://YOUR-USERNAME.github.io/pf-issue-logger/`.

## Phone use

Open the Pages URL in Safari or Chrome. Tap **開啟相機掃碼** and allow camera access. If live scanning is unavailable, use **拍攝條碼辨識**.

Issue records and compressed photos are stored only in that phone browser's Local Storage. They are not uploaded to GitHub.
